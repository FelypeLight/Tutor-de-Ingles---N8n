# ✏️ Introdução

Este repositório contém um workflow do **n8n** configurado com engenharia de prompt avançada. O objetivo principal é a correção gramatical da língua inglesa operando através de uma interface de *chatbot*.

## 🔎 Pré-requisitos

Antes de iniciar a importação do workflow, certifique-se de que seu ambiente atende aos seguintes requisitos de infraestrutura e conhecimento:

### ⚙️ Ambiente e Hardware
*   **Versão:** Instalação do `n8n` devidamente atualizada.
*   **Hardware Mínimo:** 16 GB de Memória RAM.

### 🧠 Conhecimentos Necessários
*   Conhecimento básico no protocolo **HTTP** (Requisições, Verbos e Status Codes).
*   Gerenciamento e redirecionamento de portas de rede.
